# Assignment #4 — Forms and Validation

A beginner-friendly multi-page website made with HTML, CSS, JavaScript and Bootstrap 5.

## Pages
- `index.html` — Task 0 and Task 1: basic contact form and HTML5 validation.
- `bootstrap.html` — Task 2 and Task 3: Bootstrap contact form and validation feedback.
- `register.html` — Task 4: responsive registration form.

## How to run
1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Use the navigation bar to open the other pages.

Bootstrap is loaded from a CDN, so an internet connection is needed for Bootstrap styling.

## Publish
Upload these files to a GitHub repository. In repository Settings, open Pages, select the main branch and root folder, and save. The website will be published with GitHub Pages.
